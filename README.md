Высокопроизводительный гибридный демон на Go для удаленного администрирования VPS-сервера (2 ГБ ОЗУ) через Telegram с **системой верификации пользователей (белый список + инвайт-коды)**, динамическим управлением ресурсами (cgroups v2) и интеграцией с ИИ-агентом Antigravity через Model Context Protocol (MCP).

---

## 🔒 Система верификации и регистрации пользователей

Бот работает в приватном режиме: доступ имеют **только авторизованные пользователи**. База пользователей хранится локально на сервере (`/opt/superbot/users.json`) и переживает любые перезапуски.

### 1. Как это работает для нового пользователя:
1. Когда незнакомый пользователь пишет боту (`/start` или сообщение), бот блокирует запрос и отвечает:
   > 🔒 **Доступ ограничен**  
   > Ваш Telegram ID: `123456789`  
   > Передайте ID администратору или введите: `/register ВАШ_ИНВАЙТ_КОД`
2. Администратор сервера мгновенно получает уведомление:
   > 🔔 **Запрос доступа к SuperBot:**  
   > Пользователь: @username (ID: `123456789`)  
   > Чтобы выдать доступ в 1 клик, отправьте: `/adduser 123456789 username`

### 2. Способы добавления пользователей:
* **Способ А: Через инвайт-код (приглашение)**
  * Админ пишет боту: `/invite` (код действует 24 часа) или `/invite 48`.
  * Бот генерирует одноразовый код, например: `a3f89c`.
  * Пользователь пишет боту: `/register a3f89c` — и мгновенно получает доступ.
* **Способ Б: Прямое добавление админом**
  * Админ отправляет: `/adduser 123456789 username`.
  * Пользователь сразу получает уведомление о доступе.
* **Способ В: Удаление доступа**
  * Админ отправляет: `/deluser 123456789` — доступ немедленно отзывается.
* **Просмотр списка пользователей:**
  * Команда `/users` выводит всех зарегистрированных лиц и их роли (`admin` / `user`).

## ⚡ Полный справочник команд

### 📊 Системный мониторинг (Доступно всем авторизованным пользователям):
* `/stats` — метрики CPU, LoadAvg, RAM (всего / свободно / %), ZRAM / Swap, Диск `/` и Uptime через `gopsutil`.
* `/top` — топ-5 процессов по потреблению оперативной памяти (RSS).
* `/net` — сетевой трафик (TX/RX в МБ, число пакетов) и активные IP-интерфейсы.
* `/ls <путь>` — просмотр содержимого папок с размерами файлов и бейджами типов.
* `/find <маска>` — безопасный поиск файлов с защитой от зависания (таймаут 4 сек, пропуск `/proc`, `/sys`).
* `/send <путь>` — скачивание любого файла сервера прямо в Telegram (до 50 МБ).

### 👑 Управление доступом (Только для Администратора):
* `/invite [часы]` — создать одноразовый инвайт-код для регистрации.
* `/adduser <id> [username]` — вручную добавить пользователя в белый список.
* `/deluser <id>` — удалить пользователя из белого списка.
* `/users` — показать список всех авторизованных пользователей.

### ⚙️ Управление ресурсами ядра (cgroups v2 — Только для Администратора):
* `/mode vpn` — режим **«Турбо VPN»**: `x-ui.service` получает 90% CPU и 1.2 ГБ RAM. Агент ограничен.
* `/mode ai` — режим **«Супер-Агент»**: Antigravity/OmniRoute получают 80% CPU и 1.3 ГБ RAM.
* `/mode auto` — **Сбалансированный режим** (50/50).
* `/vpn_restart` — перезапуск сервиса `x-ui.service`.
* `/ai_restart` — перезапуск сервиса `omniroute.service`.

### 🧠 Запросы к Antigravity (AI):
* Любой обычный текст без слэша (например: *"Найди ошибки в логах Nginx за последний час"*) передается напрямую в Antigravity.

## 🚀 Быстрый старт на VPS

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/ardont/vpsbot.git /opt/superbot-src
cd /opt/superbot-src
```

### Шаг 2. Автоматическая установка окружения
```bash
sudo bash scripts/install.sh
```
Скрипт автоматически:
1. Настроит сжатый пул **ZRAM 1 ГБ (zstd)** с высоким приоритетом 100 и `vm.swappiness=150`.
2. Создаст слайсы **cgroups v2** (`vpn.slice` и `ai.slice`) и привяжет к ним `x-ui` и `omniroute`.
3. Установит systemd-сервис `superbot.service` с лимитом `MemoryMax=100M`.

### Шаг 3. Заполнение секретов (`.env`)
```bash
sudo nano /opt/superbot/.env
```
Укажите ваш токен бота и ваш личный ID (он станет главным администратором):
```ini
TG_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TG_ADMIN_ID=5342950903
```
Установите права доступа:
```bash
sudo chmod 600 /opt/superbot/.env
```

### Шаг 4. Запуск и проверка
```bash
sudo systemctl start superbot
sudo systemctl status superbot
```
Просмотр логов в реальном времени:
```bash
journalctl -u superbot -f
```

## 🛡️ Безопасность

* **Постоянная база пользователей:** Файл `/opt/superbot/users.json` защищен правами `600`.
* **Автоматические алерты:** При любой попытке несанкционированного доступа главный администратор получает уведомление с Telegram ID нарушителя.
* **Изоляция systemd:** `superbot.service` работает с `NoNewPrivileges=true` и жестким лимитом памяти `MemoryMax=100M`.
